CSV Format

Required columns (header row must match exactly):

year make model purchase_date purchase_price

Optional columns:

stock_number, vin, trim, body_type, color_exterior, mileage, transmission, engine, fuel_type, drivetrain, purchase_source, status, lot_location, asking_price, notes

Date format: YYYY-MM-DD (e.g. 2026-03-15)

Status values: In Recon, Available, Pending Sale, On Hold, Wholesale, Junked

Stock numbers: Auto-generated if not provided. Rows with duplicate stock numbers are skipped.

Example row:

year,make,model,purchase_date,purchase_price,mileage,status
2022,Toyota,Camry,2026-03-01,18500,42000,In Recon
